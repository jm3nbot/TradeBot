# Trade Log

## Format
Each trade entry follows this format:

```
### YYYY-MM-DD — TICKER (buy|sell)
- Side: buy | sell
- Shares: N
- Entry price: $X.XX
- Exit price: $X.XX (if closed)
- Stop placed: trailing X% | fixed $X.XX | pending
- Stop order ID: <id>
- Catalyst: <one-line reason>
- Thesis: <brief thesis>
- Result: open | +$X (+X%) | -$X (-X%)
- Rule checks: PASS | FAIL <rule>
- Notes: ...
```
